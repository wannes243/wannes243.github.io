Smart Home Shutters

A connected roller shutter system that brings together ESP32 firmware, wireless communication, a Flutter app and a physical manual override.

The objective

Control a roller shutter from a phone while retaining a physical switch for local operation.

Firmware and hardware

The ESP32 manages the control logic and drives a two-channel relay module. The prototype demonstrates the hardware, wired controls and mobile application together.

Wireless communication

Bluetooth is used for initial configuration. Once configured, Wi-Fi and MQTT carry commands and state updates between the ESP32 and the application.

The mobile experience

The Flutter interface provides open, close and stop controls, plus an opening-percentage slider. Manual input takes priority over automatic commands.
