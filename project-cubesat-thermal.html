CubeSat Thermal Prediction

The objective

Anticipate thermal risk and support decisions about which satellite face to expose to the Sun.

Data and modelling

The project uses synthetic orbital data to train and validate an LSTM. It explores time-dependent conditions and predicted thermal behavior across the CubeSat faces.

Orientation decisions

Operational research logic uses the predicted conditions to reason about orientation. The Python implementation considers overheating and under-temperature conditions when choosing an attitude action.

What this work demonstrates

A workflow connecting time-series learning to a physical-system decision. The visual illustration on this page is generative artwork; it is not a satellite photograph or a model validation chart.
